PRAHARSHA REDDY — LOCAL PORTFOLIO

HOW TO RUN ON MAC:
1. Download and unzip this folder.
2. Open Terminal.
3. Type: cd 
   (include a space after cd), then drag the unzipped 'praharsha_portfolio' folder into Terminal and press Return.
4. Run: python3 -m http.server 8000
5. Open http://localhost:8000 in your browser.
6. To stop the local server, return to Terminal and press Control + C.

EDITING:
- index.html: text, links, project descriptions and sections.
- styles.css: colors, layout, fonts and responsive styling.
- script.js: navigation and reveal animations.
- assets/praharsha-profile.jpeg: your profile photograph.
